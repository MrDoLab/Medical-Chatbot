# Medical Chatbot

## Overview

This project is a medical question-answering app. A React chat page sends a question to a FastAPI server. The server runs a retrieval-augmented generation pipeline and returns an answer. A Streamlit page can embed the React app, and `main.py` runs the same pipeline from the command line.

The answers are generated by a language model from retrieved material. This repository does not evaluate clinical accuracy.

## Features

- React chat page that posts a question and shows the answer as Markdown.
- FastAPI endpoints for chat, listing saved sessions, and loading a session. Transcripts are written as JSON files under `chat_logs/`.
- A Flask app that reads an RSS feed and returns headline items for the news ticker.
- RAG flow in `rag_system.py`: process the question, search enabled sources in parallel, integrate the results, check the draft for hallucination, and format the output. The question-rewrite node has no edge back to search or on to formatting.
- Search sources in `components/`. `config.py` turns on MedGemma, PubMed, Tavily, and Amazon Bedrock Knowledge Base. Local documents and S3 search are implemented and turned off.
- Command-line chat in `main.py`, including `/status` and `/config`.

## Tech Stack

- Python, FastAPI (`server.py`), Flask (`fast_api_server.py`), Streamlit (`streamlit_app.py`)
- React 18 and Vite in `frontend/`, with Tailwind CSS
- LangChain, LangGraph, and the OpenAI chat model named in `config.py` (`gpt-4o`)
- PubMed, Tavily, a Hugging Face inference endpoint for MedGemma, and Amazon Bedrock Knowledge Base
- Optional S3 and Lambda search when that source is enabled

`requirements.txt` does not list `fastapi`, `uvicorn`, `flask`, `flask-cors`, `feedparser`, or `pyyaml`, even though the Python entry points import them. The React UI imports `lucide-react`, Font Awesome, and `react-markdown`, but those packages are not listed in `frontend/package.json`.

## Architecture

```
Browser (Vite, port 5173)
  chat  POST http://localhost:8000/api/chat  -> FastAPI server.py
  news  GET  http://localhost:8001/api/news  -> Flask fast_api_server.py
        |
        v
RAGSystem.run_graph
  process question -> parallel search -> integrate -> hallucination check
        |                                      |
        |                                      +-> rewrite question (no outgoing edge)
        v
  format output -> chat_logs/*.json
```

Streamlit on port 8514 embeds `http://localhost:5173`. It does not replace the chat API.

## Getting Started

These commands match the entry points in this repository. They were not run as part of this cleanup. A full answer needs the external services below.

```bash
python -m venv venv
```

Activate the virtual environment, then install dependencies:

```bash
pip install -r requirements.txt
```

Set these environment variables. Do not commit the values.

| Name | Used for |
| --- | --- |
| `OPENAI_API_KEY` | Chat model, and embeddings when local search is enabled |
| `HUGGINGFACE_API_KEY` | MedGemma requests |
| `HF_INFERENCE_ENDPOINT` | MedGemma inference URL |
| `TAVILY_API_KEY` | Tavily web search |

Bedrock, and S3 search when it is enabled, use the default AWS credential chain through boto3. The application code does not name a separate variable for the AWS secret key.

`scripts/start_api.sh` changes to the repository root, activates `venv/bin/activate` when that file exists, and starts the API if port 8000 is free:

```bash
uvicorn server:app --host 0.0.0.0 --port 8000
```

The news app listens on port 8001:

```bash
python fast_api_server.py
```

Start the React app. `npm install` was not run here.

```bash
cd frontend
npm install
npm run dev
```

The chat page calls `http://localhost:8000/api/chat`. The news ticker calls `http://localhost:8001/api/news`. Vite in `scripts/run_all.sh` is `http://localhost:5173`.

Optional Streamlit shell. It embeds `http://localhost:5173`:

```bash
streamlit run streamlit_app.py --server.port 8514
```

`scripts/run_all.sh` starts the Vite dev server and Streamlit together. It does not start the API. It also turns off Streamlit CORS and XSRF protection. That script was not run here.

Command-line chat:

```bash
python main.py
```

Prompt text is loaded from `prompt_templates.yaml` in the current working directory, so run the Python entry points from the repository root.

## Project Structure

```
server.py                 FastAPI app used by scripts/start_api.sh
fast_api_server.py        Flask app for chat and RSS news
streamlit_app.py          Streamlit page that embeds the React app
main.py                   Command-line chat
rag_system.py             LangGraph RAG pipeline
config.py                 Models, search-source switches, AWS resource names
components/               Retrievers, generator, evaluator, formatter
frontend/                 Vite React app
prompts.py                Prompt loader
prompt_templates.yaml     Prompt text
scripts/                  Standalone launchers and tools
```
